# ForgeOS brand assets

Copied from the ForgeOS branding kit (`assets/branding/ForgeOS_Master_Branding_Kit`):

- `ForgeOS_Windows_Icon.ico` from `03_Production_Assets`: window, taskbar and executable icon.
- `ForgeOS_Horizontal_Wordmark_dark.png` from `04_Application_Ready`: header wordmark for dark
  surfaces. Its background is the Midnight palette colour.

The kit's production notes apply. These are simplified reinterpretations, not exact copies of the
CGI artwork. The typeface (Inter) is not distributed, so the app uses the system font. No trademark
clearance is represented. Check the small icon sizes on Windows before a release.
