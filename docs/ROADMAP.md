# ForgeOS phased roadmap

1. Foundation: persistent tasks, GUI, logs, recovery, install guide. Next: event journal, integrity checks and Windows runtime test.
2. AI planning: Ollama connector exists; next: model discovery, structured plans, budget and cancellation.
3. Safe code execution: isolated Git worktrees, patch generation, reversible commits and policy boundaries.
4. Platform builds: Windows EXE, Android APK and web build adapters, sequential resource scheduling.
5. Autonomous QA: build/test gates, targeted diagnosis, bounded repair loops, regression and fuzz evidence.
6. GitHub workflows: checkout, branches, pull requests, reviews, status and optional releases.
7. Reliability: watchdog, backup/restore, crash recovery, event replay and detailed handoff.
8. Release: Windows smoke verification, accessibility, installer, security audit and user guide.

Never label a phase complete without objective acceptance evidence.
