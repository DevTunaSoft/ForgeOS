# ForgeOS branding

The complete supplied branding kit is preserved in
[`assets/branding/ForgeOS_Master_Branding_Kit`](../assets/branding/ForgeOS_Master_Branding_Kit/README_VERIFIED_EDITION.md).
Its `SHA256SUMS.txt` manifest was checked during import; the 64 listed files
match their published hashes.

## Application use

- The desktop window and taskbar use the transparent 128 px ForgeOS icon.
- The Windows executable uses the included multi-resolution `.ico`.
- The repository README uses the supplied GitHub banner.
- Use the light/dark wordmarks according to the supplied background variant.

The Windows build workflow packages the app icon and applies the executable
icon. Source launches load the same PNG from this repository. The full archive
also includes original concept boards, archival reference crops, proofs, the
About panel, splash art, social preview, and a simplified SVG interpretation.

## Asset and brand limits

The archive’s `06_Guidelines/Brand_Standards.md` and
`07_QA_Verification/QA_REPORT.md` are supplied brand references, not legal or
release certifications. The kit identifies the SVG and transparent flame as
simplified interpretations, says the archive does not establish trademark
clearance or print acceptance, and records that Windows application/installer
testing was not performed. Treat
`02_Reference_Crops_Not_Print_Masters/` as archival crops, not independent
production masters. No font files are included; typography recommendations
refer to fonts obtained separately under their licenses.
