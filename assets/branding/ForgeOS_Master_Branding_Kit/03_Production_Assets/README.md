# ForgeOS Production Branding Kit

## Included
- **ForgeOS_Flame_Core_Vector.svg**: manually reconstructed, editable, scalable vector *interpretation* of the approved flaming F aesthetic (not a vector trace of the detailed CGI).
- **ForgeOS_Flame_Core_Transparent_2048.png**: 2048 x 2048 RGBA transparent-background raster of the vector interpretation.
- **ForgeOS_Windows_Icon.ico**: multi-size Windows icon (16, 24, 32, 48, 64, 128, 256 px).
- **ForgeOS_Icon_*.png**: PNG sizes for UI, shortcut, installer, and About dialog.
- **ForgeOS_Cinematic_Wordmark_Original.png**: full original CGI wordmark, opaque background.
- **ForgeOS_Flaming_Emblem_Original.png**: full original CGI F emblem, opaque background.
- **ForgeOS_Fire_Splash_Original.png**: earlier fire splash artwork, opaque background.

## Usage
Use .ico for the Windows executable and installer, 256/512 PNG for application About and UI, SVG for vector-friendly interfaces, and original wordmark for splash/background branding.

## Important production note
The SVG and transparent PNG are a **clean simplified reinterpretation**, not pixel-identical conversions of the CGI images. CGI originals have complex flames, smoke, and lighting baked into their backgrounds and are not transparently extracted in this kit. Small-size icons should be visually checked on the target Windows system.
