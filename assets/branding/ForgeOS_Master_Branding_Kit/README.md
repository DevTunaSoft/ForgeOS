# ForgeOS Master Branding Kit

A consolidated collection of original AI-generated concept art, prior fire-brand kit crops, production-style derivatives, Windows icons, practical banners and visual proof sheets.

## Contents
- `01_Original_Concepts/`: original generated design boards.
- `02_Concept_Crops/`: extracted concept images; NOT independent high-resolution renders.
- `03_Production_Assets/`: prior production kit (cinematic art, simplified SVG, transparent emblem, ICO).
- `04_Application_Ready/`: practical PNG icon sizes, ICO, wordmarks, banners, splash and About panel.
- `05_High_Quality_Proofs/`: large proof sheets and actual-size icon readability sheet.
- `06_Guidelines/`: color, typography, usage and limitations.
- `SHA256SUMS.txt`: integrity hashes for every file.

## Accuracy / quality
- Originals are preserved without artificial upscaling.
- Transparent master is a **simplified illustration**; it is not a pixel-identical cutout of the cinematic art.
- The SVG in the prior kit is a simplified vector reconstruction, not a full vectorization of flame details.
- Banners and wordmarks are newly composed raster assets, not separately AI-rendered cinematic art.
- Proof sheets document appearance, not a guarantee of print production suitability.
- Windows GUI and installer runtime tests have NOT been performed.
- Some icon detail will disappear at 16–32 px; use the included size proof before release.
